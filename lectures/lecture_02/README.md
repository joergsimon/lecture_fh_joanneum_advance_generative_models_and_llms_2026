# Lecture 2: Generative model families

Lecture 2 compares autoregressive models, variational autoencoders, normalising flows, GANs, energy-based models, and diffusion models. Image examples make the mechanisms visible; each family is also connected to a language-generation use case and its limitations.

The executable material is in [`demos/`](demos/):

- [`02_vae_latent_walk.ipynb`](demos/02_vae_latent_walk.ipynb)
- [`03_flow_2d.ipynb`](demos/03_flow_2d.ipynb)
- [`04_ebm_two_well.ipynb`](demos/04_ebm_two_well.ipynb)
- [`05_diffusion_snapshots.ipynb`](demos/05_diffusion_snapshots.ipynb)
